## Private-content check

- **No purchased or third-party licensed art found in git or history.** Searched all history for added `png/gif/aseprite/ase/ogg/mp3/wav/zip` files and the whole tree for Dire Dungeon, DerNachbar, Rogarca, Minifantasy, Kenney, itch.io and "CC BY". No hits.
- Art in git today is original or generated: `render/source-assets/actor-medallions` (4 PNG sheets, 5.8 MB), `visual-assets/` (components and actors), `docs/brand/*`, `docs/design/*.png`. **Provenance to confirm with Darren:** whether `approved-affinity-sprite-sheet.png` and the medallion component sheets were produced by an image model or a tool with usage terms. If they are not fully owned, they should not stay public.
- Pixel work in progress (`ui-ascii/` Aseprite outputs, Dire Dungeon recolour tests) lives only in the **project folder** on Darren's Mac, not in this repo. Keep it that way until Primordial exists. Rule for #743: Primordial's `.gitignore` excludes raw purchased downloads; only processed sprites are committed; credit Steffen Künstler (DerNachbar) per CC BY 4.0 where required.
- The same files exist twice (`runtime/src/render/*-assets` and the `docs/design/archive` copy), so any removal must cover both and note that git history keeps them. Rewriting history is only needed if provenance fails.

## Findings that change the plan

1. `ak play` is the only adapter link to a UI, and it is already a process boundary, so extraction is cheap.
2. 431 of the archive files and ~9.7 MB of art are in `runtime`: moving them shrinks the framework package by most of its size.
3. `ui-web` imports `runtime/src/render` directly in 7 files, so those imports must be re-pointed to published packages (#742) before the move.
